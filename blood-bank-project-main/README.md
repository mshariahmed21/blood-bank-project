# قطرة حياة

نسخة التسجيل المباشر: لا تتطلب تسجيل دخول أو بريدًا إلكترونيًا أو رسائل SMS. يضيف المتبرع بياناته مباشرة، ويمكنه من جلسة المتصفح استخدام البحث والرسائل الخاصة. رابط واتساب يبقى اختياريًا حسب موافقة المتبرع.

شغّل محليًا باستخدام Python وتثبيت الحزم من `requirements.txt` ثم `python app.py`.

ملاحظة: الرسائل الخاصة مرتبطة بجلسة المتصفح الحالية؛ مسح ملفات تعريف الارتباط أو استخدام جهاز/متصفح آخر يعني أن المستخدم سيحتاج إلى التسجيل من جديد لاستخدام المحادثات. هذه نسخة تجريبية وليست بديلًا عن أنظمة التحقق القوية في بيئة إنتاجية.

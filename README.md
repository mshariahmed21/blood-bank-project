# قطرة حياة | منصة التبرع بالدم

منصة عربية باتجاه RTL لتسجيل المتبرعين والبحث حسب فصيلة الدم والمدينة. تتضمن وضعًا فاتحًا/داكنًا، محادثات خاصة بين المتبرعين، ومشاركة اختيارية لرقم التواصل عبر واتساب.

## التشغيل على Windows / PyCharm
1. افتح مجلد `blood-bank-project-main`.
2. ثبّت المتطلبات: `py -m pip install -r requirements.txt`
3. شغّل: `py app.py`
4. افتح `http://127.0.0.1:5000`.

## التحقق بالبريد الإلكتروني
اضبط المتغيرات التالية في Render > Environment:
- `SMTP_EMAIL`: عنوان Gmail الذي يرسل رموز التحقق.
- `SMTP_APP_PASSWORD`: كلمة مرور تطبيق Google (16 حرفًا)، ولا تشاركها أو تضعها في الكود.
- `SMTP_HOST`: اختياري، الافتراضي `smtp.gmail.com`.
- `SMTP_PORT`: اختياري، الافتراضي `465`.
- `SECRET_KEY`: قيمة عشوائية طويلة وسرية في بيئة الإنتاج.
- `DATABASE_URL`: رابط PostgreSQL دائم على Render للحفاظ على البيانات بين عمليات النشر.

تسجيل الدخول والتحقق يتمان بالبريد الإلكتروني فقط. رقم الجوال يبقى ضمن بيانات المتبرع للتواصل، ولا يُعرض خيار واتساب إلا إذا وافق المتبرع صراحةً على مشاركة رقمه. لا تفعّل `OTP_DEMO_MODE=1` على الموقع العام؛ وضع التجربة لا يرسل بريدًا حقيقيًا.

## قاعدة البيانات والبيانات القديمة
يُستخدم SQLite محليًا. عند التشغيل على Render، يُفضّل ربط PostgreSQL دائم عبر `DATABASE_URL`. يحافظ التحديث على سجلات المتبرعين القديمة ويضيف حقل البريد الإلكتروني عند الحاجة. السجلات القديمة لا تحتوي بريدًا موثقًا تلقائيًا؛ لذلك لن يمكن تسجيل الدخول إليها بالبريد حتى يُربط بريدها بالسجل من خلال تحديث إداري آمن. لا تحذف قاعدة البيانات القديمة.

## ملاحظات الخصوصية والسلامة
رقم الجوال لا يظهر في نتائج البحث إلا إذا اختار المتبرع صراحةً الموافقة على إظهاره. المنصة للتواصل المبدئي ولا تقرر الأهلية الطبية؛ يجب تنسيق التبرع مع جهة صحية معتمدة. راجع متطلبات الخصوصية والموافقات قبل الإطلاق العام.

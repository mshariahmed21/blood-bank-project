# قطرة حياة

منصة تجريبية للتواصل الأولي بين المتبرعين والباحثين عن متبرعين. لا تستبدل إجراءات بنوك الدم أو التقييم الطبي.

## التشغيل المحلي
1. `pip install -r requirements.txt`
2. `python app.py`
3. افتح `http://127.0.0.1:5000`

## إعدادات مهمة
- اضبط `SECRET_KEY` بقيمة عشوائية طويلة قبل النشر.
- احتفظ بنفس `DATABASE_URL` في Render؛ لا تحذف قاعدة البيانات.
- اضبط `ADMIN_PASSWORD` للوصول إلى `/admin`.
- إشعارات الرسائل الحالية تعتمد على الاستطلاع الدوري أثناء فتح الموقع. إشعارات Push عند إغلاق الموقع تحتاج خدمة Push/Service Worker ومفاتيح VAPID، ولم تُفعّل في هذه النسخة.
- خيار البريد في الإعدادات يحفظ التفضيل فقط؛ يلزم ربط مزود بريد لإرسال تنبيهات فعلية.

## حماية البيانات
خذ نسخة احتياطية قبل أي ترحيل. لا ترفع قاعدة البيانات أو الأسرار إلى GitHub.


## تثبيت قطرة حياة كتطبيق (PWA)

المشروع يدعم التثبيت على الجوال من خلال المتصفح، ويظل الموقع وقاعدة البيانات ولوحة الإدارة مشتركة مع نسخة الويب. يلزم فتح الموقع عبر HTTPS (Render يوفر HTTPS).

- **Android / Chrome:** افتح رابط الموقع، ثم اختر «تثبيت التطبيق» إذا ظهر الزر، أو من قائمة Chrome اختر «تثبيت التطبيق» / «إضافة إلى الشاشة الرئيسية».
- **iPhone / Safari:** افتح الموقع في Safari، اضغط زر المشاركة، ثم «إضافة إلى الشاشة الرئيسية».
- بعد التثبيت يفتح التطبيق بواجهة مستقلة، ويستخدم نفس الحسابات والبيانات الموجودة على الموقع.

يتضمن المشروع Web App Manifest وأيقونات وService Worker. يتم تخزين ملفات الواجهة العامة فقط مؤقتًا؛ لا يتم تخزين صفحات الحسابات أو الرسائل أو بيانات المتبرعين في ذاكرة العمل دون اتصال.

**تنبيه:** التثبيت لا يعني أن إشعارات Push الخلفية أصبحت مفعّلة. إشعارات الرسائل حتى بعد إغلاق التطبيق تحتاج إعداد مفاتيح VAPID وربط اشتراكات الأجهزة بخدمة إرسال خلفية، ويجب تنفيذ ذلك قبل الإعلان عن توفرها.

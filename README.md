
# 🩸 قطرة حياة

منصة ذكية تجريبية لإدارة التبرع بالدم والبحث عن المتبرعين حسب فصيلة الدم والمدينة.

## فكرة المشروع
يساعد الموقع على البحث عن متبرعين بالدم حسب الفصيلة والمنطقة الجغرافية.

## التقنيات المستخدمة
- Python
- Flask
- HTML
- CSS

## مميزات المشروع
- البحث حسب فصيلة الدم.
- البحث حسب المدينة.
- واجهة عربية عصرية.
- عرض نتائج البحث التجريبية.

## إعداد المتدرب
**الاسم:** مشاري أحمد مخرش  
**الكلية:** الكلية التقنية بجازان

> ملاحظة: بيانات المتبرعين المعروضة تجريبية وليست بيانات حقيقية.
